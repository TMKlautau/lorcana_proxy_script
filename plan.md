# Plan: Lorcana proxy PDF from `test_list.txt`

## Context
`test_list.txt` is a Lorcana decklist (`<qty> <Name> - <Version>` per line; 17 unique cards, 60 total). Goal: produce a printable A4 PDF of those card images, laid out at real card size with cutting lines, generated by a Python script run in the project's existing uv venv (`.venv`, Python ≥3.14). The project is currently a bare uv skeleton (`main.py` prints hello, no deps).

## Step 0 — Export this plan
Copy this plan to `D:\Documents_D\quick_projects\lorcana_decks\plan.md`.

## Step 1 — Dependencies (in current venv)
`uv add requests reportlab pillow` (updates `pyproject.toml` + `uv.lock`, installs into `.venv`). Run everything with `uv run` / `.venv\Scripts\python.exe`.

## Step 2 — Implement `main.py`
Replace the hello-world with a small CLI: `python main.py [decklist] [-o output.pdf]` (defaults: `test_list.txt`, `deck.pdf`).

1. **Parse decklist** — regex `^(\d+)\s+(.+)$`; split name on the first `" - "` into `name` / `version` (cards like "You Broke My Smolder" / "Strength of a Raging Fire" have no version → actions/songs). Skip blank lines.
2. **Card lookup via Lorcast API** (`https://api.lorcast.com/v0`, free, no key):
   - `GET /sets` then `GET /sets/{id}/cards` for each set; build a dict keyed by normalized `"name - version"` (lowercase, unify curly/straight apostrophes, collapse whitespace). Cache the combined JSON to `cache/cards.json` so reruns don't hit the API.
   - ~100 ms sleep between requests (Lorcast's requested rate).
   - If a card isn't found, fall back to `GET /cards/search?q=<name>` and match on name+version; if still not found, report it and render a placeholder box with the card name instead of failing.
   - If a card has multiple printings, pick the first (the regular, non-enchanted one where possible).
3. **Download images** — `image_uris.digital.large` → `cache/images/<card_id>.avif|jpg`; skip if cached. Open with Pillow and convert to RGB JPEG for reportlab (Pillow handles AVIF on recent versions; if the URL is AVIF and fails, use the `.jpg`/`normal` variant).
4. **Layout with reportlab** (A4 = 210×297 mm):
   - Card size 63×88 mm (standard Lorcana), 3×3 grid = 189×264 mm, no gutter, centered → margins 10.5 mm left/right, 16.5 mm top/bottom.
   - Expand list by quantity → 60 cards → 7 pages (last page 6 cards).
   - **Cutting lines**: thin (0.25 pt) light-grey lines along every card edge across the grid, plus darker crop marks extending into the margins at each column/row boundary so cuts are visible after the first trim.
5. Print a summary (cards found / missing, pages written, output path).

Also add `cache/` and `*.pdf` to `.gitignore`.
